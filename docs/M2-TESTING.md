# M2 全量回归清单

> 适用版本：v1.2-M2
> 使用方式：逐条执行并在通过后勾选 `- [ ]` → `- [x]`。
> 涉及模块：记账、备忘录、计时器与番茄钟、日历、跨模块关联动作。

## 一、记账 `/finance`

- [ ] **1. 账户切换隔离**
  操作：切换顶部账户下拉（含「全部账户」）。
  预期：只影响本页统计与月度卡片，任何流水数据不被改动。

- [ ] **2. 记支出 / 记收入**
  操作：「记支出」「记收入」各录一条。
  预期：流水列表按日期倒序出现，金额红/绿正确，月度卡片支出、收入、结余同步变化。

- [ ] **3. 流水编辑与删除**
  操作：点击任意流水修改金额/分类/账户/日期并保存；再点「×」删除一条。
  预期：保存后列表与统计同步；删除后当月合计与分类统计立即回落。

- [ ] **4. 统计标签**
  操作：切到「统计」标签。
  预期：支出分类条形图百分比之和为 100%，无数据时显示空态。

- [ ] **5. 预算标签**
  操作：切到「预算」标签，并让某分类流水累加至超过预算。
  预期：各支出分类进度条随流水累加；超预算时变红。

- [ ] **6. 收支分类改名与删除**
  操作：把一个已被流水引用的分类改名；再新建一个被引用的分类并删除。
  预期：改名后历史流水分类同步改名（不产生「未分类」）；删除后关联流水落到「未分类」，不残留孤儿引用。

- [ ] **7. 周期账单自动生成**
  操作：新建一条周期规则，进入记账页或把应用切回前台。
  预期：自动补记当期流水，列表带「周期」标记，且不会重复生成。

- [ ] **8. 年度视图**
  操作：切到「年度」标签。
  预期：12 个月收支与年度总支出、总收入、结余合计一致。

## 二、备忘录 `/memos`

- [ ] **1. 新建备忘录并选分类**
  操作：新建普通备忘录，选择分类后保存。
  预期：瀑布流卡片出现在对应分类下，发布后立即可见。

- [ ] **2. 购物清单勾选**
  操作：新建「购物清单」，逐条勾选条目，并在编辑弹窗内增删条目。
  预期：进度条与已完成数递增，全部勾完状态正确；增删条目后进度同步。

- [ ] **3. 分类管理**
  操作：把一个备忘录分类改名；再删除一个已有卡片的分类。
  预期：改名后该分类下卡片标签同步；删除后该分类备忘归到默认分类，条目不丢。

- [ ] **4. 置顶与搜索**
  操作：点击卡片置顶按钮；在搜索框输入内容或清单条目关键词，再清空。
  预期：置顶卡片排到最前，再次点击可取消；搜索结果实时过滤，清空后恢复全量。

- [ ] **5. 编辑与删除**
  操作：编辑并删除若干备忘录，然后刷新页面。
  预期：列表与数量即时同步，刷新后数据仍在。

- [ ] **6. 窄屏布局**
  操作：把窗口收窄到移动端宽度。
  预期：瀑布流变为单列/双列，无横向溢出。

## 三、计时器 `/timer` 与番茄钟 `/pomodoro`

- [ ] **1. 正计时全流程**
  操作：开始 → 暂停 → 继续 → 结束。
  预期：计时递增；暂停时数值冻结，继续后接着走；结束时响铃并出现「已记录 N 分钟到时间统计」。

- [ ] **2. 结束态撤销**
  操作：结束态点击「撤销」。
  预期：刚写入的时间块被删除，时间统计中同步消失。

- [ ] **3. 倒计时到点**
  操作：设定目标时长开始倒计时，等待到点。
  预期：自动结束并落库；运行/暂停中模式与输入锁定。

- [ ] **4. 运行中刷新恢复**
  操作：运行中刷新页面。
  预期：恢复到运行态且剩余/已用时间连续，不重置、不补记重复时间块。

- [ ] **5. 跨模块互斥**
  操作：计时器运行中打开番茄钟并点开始；再反向操作一次；最后结束当前会话后重新启动。
  预期：运行中均被拦截并提示；结束当前会话后可正常启动。

- [ ] **6. 番茄钟绑定待办与计数规则**
  操作：绑定一个待办，分别用倒计时与正计时各跑一轮，再跑一轮不足 1 分钟的会话。
  预期：专注记录带关联待办；倒计时整轮计入「今日番茄」个数，正计时只计时长不计个数；不足 1 分钟只留时间块不计个数。

- [ ] **7. 番茄钟撤销与统计一致性**
  操作：番茄钟结束后点「撤销」，再刷新页面查看统计。
  预期：专注统计与时间块同时回退；刷新后统计仍与历史一致。

## 四、日历五视图 `/calendar`

- [ ] **1. 默认入口**
  操作：直接访问 `/calendar`。
  预期：默认月视图，锚点为今天，地址栏出现 `view=month&date=今天`。

- [ ] **2. 月视图渲染**
  操作：查看月视图，并收窄窗口到窄屏。
  预期：固定 6 行 42 格，周一为首列；有内容的格子最多显示 3 条 + 「还有 M 条」；窄屏切换为 4 色点摘要，无错位。

- [ ] **3. 视图切换与刷新保持**
  操作：依次切换 月 / 周 / 三日 / 日 / 年，然后刷新；再重新进入无 query 的 `/calendar`。
  预期：URL 的 `view` 随之变化；刷新后停留在同一视图与日期；无 query 时使用上次视图偏好。

- [ ] **4. 上一屏/下一屏/今天**
  操作：点击「‹」「›」「今天」。
  预期：按当前视图粒度（月/周/3 天/1 天/年）平移；「今天」回到今天并替换历史记录（后退不会卡在今天之前）。

- [ ] **5. 周视图**
  操作：切到周视图；再把窗口收窄到 <640px。
  预期：7 列时间轴 + 底部「N 条未排期」；窄屏降级为每日卡片列表，不出现横向滚动条。

- [ ] **6. 日 / 三日视图**
  操作：切到日视图与三日视图，滚动并观察当前时间位置。
  预期：24 小时刻度；同一视图内各列共享滚动；首次进入自动定位到当前时间（当天）或 08:00；当前时间红线位置正确。

- [ ] **7. 年视图热力与下钻**
  操作：切到年视图，点击某个月份，再点击某个日期。
  预期：12 个月热力四档按条数加深；点月份进入该月的月视图，点日期进入该日的日视图。

- [ ] **8. 异常时间块**
  操作：构造一条结束时间 > 24 的时间块，在日历中查看并点击。
  预期：渲染截断到 24 点并带红框 + ⚠，数据本身未被改写；点击该块跳转 `/time`。

- [ ] **9. 待办时间点**
  操作：查看有具体时间的待办与无时间的待办。
  预期：有时间的待办在时间轴上显示为时间点 pin；无时间的待办只出现在月/年计数与「未排期」中。

- [ ] **10. 前进后退**
  操作：连续操作后使用浏览器前进/后退。
  预期：视图与日期按历史回放，不出现空白页。

## 五、跨模块关联动作

- [ ] **1. 计时器 → 日历与时间统计**
  操作：计时器跑一轮并结束，查看日历当天与 `/time` 当天。
  预期：日历日/三日/周出现对应时间块；时间统计饼图、分类统计与总时长同步增加。

- [ ] **2. 番茄钟 → 日历、时间统计与番茄统计**
  操作：番茄钟完成一轮，查看日历当天、`/time` 当天与番茄统计。
  预期：出现「专注」时间块；番茄统计个数与时长与之一致。

- [ ] **3. 待办完成 → 时间块归属日期**
  操作：勾选完成一个 `due_date` 不是今天的待办并填写用时。
  预期：时间块归属该任务自己的 `due_date`；日历与时间统计在对应日期可见。

- [ ] **4. 日历 → 时间统计日期预选**
  操作：在日历中点击某个时间块。
  预期：跳转 `/time?date=当天`，页面日期按钮直接显示该日，饼图与明细即为该日数据。

- [ ] **5. 日历 → 待办日期预选**
  操作：在日历中点击某个待办。
  预期：跳转 `/todos?date=当天`，列表已按该日筛选，新增任务默认落在该日。

- [ ] **6. 非法日期参数回落**
  操作：手动访问 `/time?date=2026-13-01`、`/todos?date=2026-02-30`，以及 `?date=` 为空。
  预期：安全回落今天，不白屏不报错。

- [ ] **7. 模块开关拦截**
  操作：在设置中关闭某模块，再从侧栏与直接输入路由两种方式访问。
  预期：侧栏入口消失；直接访问自动回首页，不出现半渲染页面。

- [ ] **8. 分区隔离**
  操作：对比「规划」与「生活」两个侧栏分组下的数据，并刷新/清缓存后复查。
  预期：记账数据不出现在规划侧任何统计中，两组数据各自独立且刷新后正确恢复。
